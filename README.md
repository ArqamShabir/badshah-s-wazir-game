# Badshah ka Wazir

## Project info

Badshah ka Wazir is a four-player hidden-role party game built with Vite and React. Use this repo to develop and deploy the app without any external platform requirements.

## How can I edit this code?

You only need Node.js and npm installed — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Clone the repository using your Git URL
git clone <YOUR_GIT_URL>

# Enter the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the dev server with hot reload
npm run dev
```

You can also edit files directly on GitHub or in GitHub Codespaces; commit and push changes as usual.

## What technologies are used for this project?

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## How can I deploy this project?

Build the production bundle and serve it from any static host or CDN:

```sh
npm run build
npm run preview # optional local check of the built assets
```

Upload the `dist/` directory to your hosting provider or integrate with your preferred CI/CD pipeline.
